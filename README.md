# 实时战争游戏 (Real-time War Game)

纯 HTML / Canvas / JS 单文件实现的**实时制**策略战争游戏，无需构建、无依赖，浏览器直接打开 `index.html` 即可玩（也可部署到 GitHub Pages）。

## 游戏目标
你（蓝色）对抗 AI（红色）。**消灭敌方全部单位即胜利**；己方单位全灭则失败。

## 兵种
| 兵种 | 特点 |
|------|------|
| 步兵 | 血少、攻速快、射程近。在**森林**可隐藏（被敌方侦测概率大幅降低，需极近才可见）。 |
| 坦克 | 血厚、单发伤害高、攻速慢。在**平原**有攻击增益；进入**森林**行动迟缓且战力削弱。 |
| 战机 | 无视地形移动限制（各格移动成本恒定）、**视野最大**、可远程打击地面目标。 |

所有单位在射程内自动开火，玩家主要负责**机动走位**。

## 地形
- **山谷**：对全体提供防御加成
- **平原**：坦克增益、步兵中性
- **森林**：步兵隐身、坦克削弱/减速
- **沙漠**：步兵减速
- **城市**：中立据点，可回血、补弹、招募（见下）

## 城市（中立据点）
- 城市**不预设阵营**，归属由**城内各边存活单位数量**实时判定：己方多→蓝框、敌方多→红框、持平或空城→灰框。
- 只有**归属己方**的城市才为本方提供补给：回血、补弹药、恢复“暴露度”。
- 招募新兵必须在**归属己方**的城市内进行。
- 城市越随机分布越多张，开局中央一座、其余环绕。

## 时间与战斗力衰减
- 采用真实时间推进（可暂停 / 1x / 2x）。
- 每单位累计“暴露度”：在**城市外**停留越久，战斗力越低（最多 -50%）；回到**归属己方**的城市会逐渐恢复。
- 资金随时间每秒 +10，击毁敌方单位 +50。

## 视野与迷雾
- 未探索区域为**全黑**；探索过但当前无视野的区域为**暗灰**；当前在视野内的区域为**亮色**。
- 视野由各单位的视野半径实时计算（战机半径最大）。
- 开局中央一带已点亮，作为初始侦察范围。
- 城市边框仅在其被探索/可见时显示。

## 操作
| 操作 | 说明 |
|------|------|
| 左键单击 | 选中己方单位；点空格下达移动指令（相机跟随） |
| 左键拖动 | 框选多个己方单位 |
| `W` `S` `A` `D` / 方向键 | 平移相机（自由探索地图） |
| `Shift` + 方向键 | 加速平移 |
| 右上角按钮 | 暂停 / 1x·2x 加速；显示资金、时间、双方存活单位数 |
| 右栏按钮 | 招募步兵 / 坦克 / 战机（需己方单位在归属己方的城市） |

选中单位时相机自动跟随；一旦使用键盘平移，改为手动控制，直到取消选中。

## 规则细节
- 伤害 = 有效攻击力 ×（1 - 目标地形防御）× 随机浮动；有效攻击力 = 基础攻击 ×（1 - 暴露度×50%）× 地形攻击修正。
- 每次攻击消耗 1 发弹药，弹药耗尽无法开火。
- 一格可容纳多个单位；寻路采用 A*（按地形移动成本加权）。
- AI 行为：血量/弹药低于 40% / 30% 时撤往最近的己方城市补给，否则追击最近的玩家单位。

## 技术实现
- 单文件 `index.html`（约 200 行 HTML/CSS + 两段 `<script>`）
- `requestAnimationFrame` 主循环，固定时间步推进
- 地图 / 城市由固定种子随机生成（保证每次开局一致）
- Canvas 视口裁剪渲染（60×60 大地图，只显示 720×720 一小块）
- 无第三方依赖

## 本地运行
```
# 直接双击 index.html，或用任意静态服务器
npx http-server -o
```
