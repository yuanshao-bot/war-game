# 实时战争游戏 (Real-time War Game)

纯 HTML/Canvas/JS 单文件实现的实时制策略战争游戏，浏览器直接打开 `index.html` 即可玩，无需构建。

## 玩法
- 玩家 vs 简单 AI，目标：消灭敌方全部单位
- 三种兵种：步兵 / 坦克 / 战机
- 五种地形：山谷 / 平原 / 森林 / 沙漠 / 城市
  - 步兵在森林可隐藏（被侦测概率降低）
  - 坦克在平原增益、在森林削弱
  - 战机不受地形限制、视野最大
- 城市中立，归属由城内各边单位数量判定（边框显示归属）；己方城市可回血/补弹/招募
- 城市外停留越久战斗力衰减
- 货币系统：每秒收入 + 击杀奖励，可招募新兵
- 迷雾视野：未探索全黑、已探索变灰、当前可见变亮；战机提供大范围视野

## 操作
- 左键单击：选中己方单位 / 下达移动指令
- 左键拖动：框选多个单位
- WASD / 方向键：平移相机（Shift 加速）
- 选中单位时相机自动跟随，使用键盘后改为手动控制
- 右上角：暂停 / 加速 / 资金 / 时间 / 双方单位数
- 右栏：招募按钮（需己方单位在归属己方的城市内）

## 文件
- `index.html`：完整游戏（单文件）

## 技术
- 纯前端，无依赖
- `requestAnimationFrame` 主循环
- A* 寻路（地形成本加权）
- 种子随机地图与城市生成
