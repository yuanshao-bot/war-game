# 实时战争游戏 (Real-time War Game)

纯 HTML / Canvas / JS 多模块实现的**实时制**策略战争游戏，无构建、无依赖。
浏览器直接打开 `index.html` 即可玩，在线版: https://yuanshao-bot.github.io/war-game/

## 游戏目标
你（蓝色）对抗简单 AI（红色）。**消灭敌方全部单位即胜利**，己方全灭则失败。
开局双方各有 步兵×1 + 坦克×1 + 战机×1。

## 兵种
| 兵种 | 造价 | 特点 |
|------|------|------|
| 步兵 | 100 | 血少、攻速快、射程近。**森林中隐身**（敌方需极近才可见） |
| 坦克 | 250 | 血厚、单发伤害高。**平原攻击×1.3，森林×0.7 且移动迟缓** |
| 战机 | 180 | 无视地形（移动成本恒定）、**视野最大（7格）**、可远程打击 |

射程内自动开火，玩家主要负责机动走位。

## 地形
- **山谷**：对全体提供防御减伤
- **平原**：坦克增益
- **森林**：步兵隐身、坦克削弱/减速
- **沙漠**：步兵减速
- **城市**：补给点（见下）

## 城市（14 座，随机分布）
- 城市**不预设阵营**，归属由**城内双方存活单位数量**实时判定：己方多→蓝框、敌方多→红框、持平或空城→灰框
- 只有**归属己方**的城市才补给：回血(20/s)、补弹药(3/s)、回复暴露度
- **招募新兵必须让自己的单位待在自己归属的城里**（点击右侧按钮）
- 城市边框仅在其 3×3 区域完全可见时才显示（迷雾下不会露出）

## 时间与战斗力衰减
- 真实时间推进，可暂停 / 1x / 2x
- 每单位累计"暴露度"：**城市外**每秒 +3%、中立城市 +2%、**己方城市**每秒 -15%
- 暴露度上限使战斗力最多 -50%（回城恢复）
- 资金：每秒 +10，击毁敌方单位 +50

## 视野与迷雾
- **未探索**=纯黑；**已探索但当前无视野**=暗色（保留地形，不再全黑）；**当前在视野内**=亮色
- 视野 = 单位视野半径（战机最大）。**曾经亮过的区域不会再次熄灭**（经典 RTS 迷雾）
- 开局种子视野：点亮玩家基地、敌方基地、地图中央 3 个 24×24 区域，保证开局中央可见
- 玩家基地 = 离地图中心最近的城市，敌方基地 = 最北端城市（开局相距较远，作为"前线"）

## 操作
| 操作 | 说明 |
|------|------|
| 左键单击 | 选中己方单位；再次点空格下移动令（虚线指向目标） |
| 左键拖动 | 框选多个己方单位 |
| WASD / 方向键 | 平移相机；Shift 加速 |
| 左上角小地图 | 点击跳转相机到该位置 |
| 顶栏按钮 | 暂停 / 1x·2x |
| 右侧按钮 | 招募步兵 / 坦克 / 战机 |

选中单位时相机自动跟随；一旦按键盘平移则转手动控制，直到取消选中。

## 战斗规则
- 伤害 = 基础攻击 ×(1-暴露度×50%) × 地形修正 ×(1-目标防御) × (1±20% 浮动)
- 每次开火消耗 1 发弹药，弹药耗尽无法开火
- A* 寻路（按地形移动成本加权），一格可容纳多单位

## AI 行为（简单）
- 血量 <40% 或弹药 <30% → 撤往最近己方城市补给
- 否则追击最近玩家单位
- 每 0.4s 决策一次

## 技术结构（多文件 ES 模块）
| 文件 | 职责 |
|------|------|
| `js/config.js` | 全部数值（兵种/地形/衰减/城市/AI 参数），改数值不碰逻辑 |
| `js/map.js` | 固定种子地形+城市生成、A* 寻路 |
| `js/unit.js` | 单位状态、暴露度衰减、移动 |
| `js/fog.js` | 迷雾：种子视野、实时视野、"seen"常亮保留 |
| `js/combat.js` | 目标选择、开火、伤害计算 |
| `js/economy.js` | 资金、招募、击杀奖励 |
| `js/ai.js` | 简单 AI 决策 |
| `js/camera.js` | 相机：居中/跟随/键盘平移/小地图跳转 |
| `js/input.js` | 点选/框选/移动指令 |
| `js/render.js` | 主视口渲染（视口裁剪、迷雾、城市边框、单位、连线） |
| `js/minimap.js` | 左上角 180×180 小地图 |
| `js/main.js` | 主循环、状态组装、UI |

- 地图 60×60（世界 1440×1440px），视口 720×720 只显示一小块
- `requestAnimationFrame` 主循环，迷雾每 0.3s 刷新
- 无第三方依赖

## 本地运行
双击 `index.html`，或任意静态服务器（如 `npx http-server -o`）。
